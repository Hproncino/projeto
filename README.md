Projeto integrador do 6º semestre de Ciência da Computação (Uninove) focado em predição de vendas com Machine Learning, aplicando Regressão Linear para estimar resultados a partir de dados históricos. Atuei no pipeline de tratamento e análise de dados, treinamento e avaliação do modelo e visualização de insights, com apoio de notebooks para experimentação e uma demo simples em Streamlit.

Stack: Python • Pandas • Scikit-learn • Matplotlib/Seaborn • Jupyter • Streamlit
